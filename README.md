I developed a desktop-based AI-powered application that automates invoice generation and provides real-time transaction analytics for small businesses. Using Python along with Pandas and NumPy, I handled data preprocessing, transformation, and aggregation. A custom PyTorch neural network model was implemented to classify and process user inputs, enhancing automation accuracy. I built a modern and intuitive user interface using CustomTkinter, and used SQLite as a lightweight, local database for efficient data storage. Key features include PDF invoice generation, Google Drive backup integration, and WhatsApp-based invoice sharing. The system is designed to improve operational efficiency, reduce manual errors, and provide insights through analytics dashboards. This project deepened my understanding of AI, GUI design, and full-stack desktop application development, while strengthening my skills in Python and data-driven software engineering.
